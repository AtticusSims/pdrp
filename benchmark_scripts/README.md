# Benchmark & Analysis Scripts

Reproducible harness, RO-Crate validator, Okapi BM25 / PDRP tool engine (`tools_engine.py`), cross-family blinded judging, within-weight reasoning toggle ablation (`08_run_reasoning_ablation.py`), and human validation scoring scripts (`07_score_human_validation.py`) from the *Design Science* study.

- Set `OPENROUTER_API_KEY` in your environment to replicate cloud endpoints; local open-weight models run via Ollama `/api/chat`.
- The corpus-staging helper referencing two unpublished internal manuscripts (`01_prepare_corpora.py`) is withheld until those manuscripts are published.
